# Ícones 3D dos módulos

**Para ligar um ícone, basta soltar o arquivo nesta pasta.** O componente
detecta sozinho (é Server Component, checa o disco em build) — não precisa
editar conteúdo nem código.

## Nomes dos arquivos

| Arquivo    | Módulo                              |
|------------|-------------------------------------|
| `nc.png`   | Nova contratação e fase preparatória |
| `esp.png`  | Especialista Licita Pública          |
| `pp.png`   | Pesquisa de Preços                   |
| `aj.png`   | Análise Jurídica                     |
| `ct.png`   | Gestão de Contratos                  |
| `fx.png`   | Painel do Fiscal                     |
| `rp.png`   | Gestão de Ata (RP)                   |
| `cg.png`   | Controladoria e Compliance           |

## Especificação

- **Formato:** PNG com fundo TRANSPARENTE
- **Dimensão:** quadrado, 1024 px ou mais (o do ChatGPT sai 1254 × 1254)
- **Enquadramento:** objeto centralizado, ~12% de margem — o card já aplica
  o halo de luz e a sombra de contato

Sem o arquivo, o card mostra o placeholder (sigla em outline sobre o halo
azul). Nunca uma imagem quebrada, então dá pra ir ligando um de cada vez.
